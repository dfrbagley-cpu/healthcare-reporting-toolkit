Profiles contain settings and column names, never selected data. Dates and coverage are entered each run.

Column mappings and additional rules

Mappings use one source=destination per line. Names after mapping are used by all rules. Values remain text; identifiers keep leading zeros.

Dates must be YYYY-MM-DD. Same-day events pass. The measure's service date remains required even if another chronology check allows an open end.

Results

Summaries contain rule names, dates, counts, and file fingerprints. Detailed exports contain keys and values. Review sensitivity before sharing. These are check results, not approval or proof of authenticity.

What this establishes

A complete result accounts for the count difference under your selected definition. It does not infer causes, reconstruct overwritten history, validate clinical decisions, or add together distinct-person counts. Changed records that remain eligible contribute zero to this count; inspect other changes in the extract comparison.
